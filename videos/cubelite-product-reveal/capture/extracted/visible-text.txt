[h1] CubeLite
[p] Kubernetes Context Aggregator
[p] Discover, switch, and manage Kubernetes contexts from a unified interface — fast, local‑first, and privacy‑respecting.
[a] Download for macOS
[a] All platforms
[span] Latest release: v0.5.0
[span] 📸 Screenshot coming soon
[h2] Features
[h3] Context Switching
[p] Switch active Kubernetes context with a single click and persist the change to disk automatically.
[h3] Multi-Kubeconfig
[p] Resolves
[code] KUBECONFIG
[p] env paths, merges multiple files, and picks the first file's
[code] current-context
[div] 🖥️
[h3] Lens-like GUI
[p] NavigationSplitView sidebar listing all contexts with a detail pane for Pods, Namespaces, and Deployments.
[h3] Menu Bar Quick-Switch
[p] Click the status-bar icon to switch context without opening the main window — perfect for fast workflows.
[h3] Secure Credentials
[p] Bearer tokens and client certificates stored in the OS Keychain — never in plain text config files.
[h3] No Telemetry
[p] Zero analytics, zero call-home, zero cloud accounts. Your cluster data stays on your machine.
[h2] Architecture
[p] CubeLite is a monorepo with three independent layers — no runtime dependency between them.
[h3] 🦀 Rust Core
[code] crates/cubelite-core
[p] Kubeconfig parsing, kube-rs client, resource types. Rust 1.82+, tokio, thiserror, anyhow.
[h3] 🍎 macOS App
[code] apps/macos
[p] Native Swift 6 + SwiftUI menu-bar and main window. macOS 14+, Observation framework, direct URLSession to k8s API.
[h3] 🖥️ Desktop App
[code] apps/desktop
[p] Cross-platform via Tauri v2 + Svelte 5 + TypeScript. shadcn-svelte, Tailwind v4, Vitest, Playwright.
[code] cubelite/
├── crates/
│   └── cubelite-core/      ← Rust library
├── apps/
│   ├── desktop/            ← Tauri v2 + Svelte 5
│   └── macos/              ← Swift 6 + SwiftUI
├── design/                 ← Design tokens
